## ✅ Definition of Done (DoD)

### Geral (todos os itens)
- [ ] Item revisado e aprovado
- [ ] Sem pendências ou bugs conhecidos bloqueantes
- [ ] Documentado
- [ ] Versionado e mergeado na branch principal do projeto

### Features (FT)
- [ ] Funcionalidade implementada conforme os critérios de aceite da User Story
- [ ] Testada manualmente em ao menos 1 dispositivo/tamanho de tela
- [ ] Sem erros ou warnings no console
- [ ] Código segue o padrão de estilo definido no Style Guide
- [ ] Integrado corretamente com o Banco de Dados

### Design (DG)
- [ ] Tela/componente segue o Style Guide
- [ ] Design revisado e aprovado
- [ ] Assets exportados e disponíveis para o desenvolvimento

### Infraestrutura (IF)
- [ ] Estrutura/esquema documentado
- [ ] Testado em ambiente de desenvolvimento sem erros de conexão
- [ ] Backup ou rollback possível em caso de falha

### Processo (PR)
- [ ] Documento revisado e validado
- [ ] Disponível em local acessível a todos
